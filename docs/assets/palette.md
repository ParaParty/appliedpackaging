# 资产调色板

本文定义 Applied Packaging 资产阶段的颜色、材质和命名基线。正式设计说明仍以 `docs/04-asset-spec.md` 为准，本文件给材质生成和验收使用。

## 1. 主材质

| 材质 | 用途 | 建议颜色 |
| --- | --- | --- |
| quartz_panel | AE2 风格浅色外壳、包裹主体 | `#d8dde0`, `#bfc7cb`, `#8f9aa0` |
| dark_metal | 方块框架、包裹角扣、总线底座 | `#2a3036`, `#414951`, `#68727a` |
| fluix_core | 默认封印、能量槽、高亮 | `#7e6bff`, `#b05cff`, `#4fc3ff` |
| glass_channel | 透明装配腔、能量窗口 | `#5ed7ff`, `#a985ff`, alpha 40-75 |
| shadow_slot | UI 槽位、凹槽、扫描口 | `#15191d`, `#252b31`, `#38424a` |
| warning_light | 阻挡状态、错误灯 | `#ff4c4c`, `#ffb84d` |

## 3. 风格规则

必须保持：

```text
AE2 风格的石英/金属/Fluix 电子封装感
大块面、清晰边界、低噪声
包裹图标在 16x16 和 32x32 都可读
机器方块可由简单 cuboid 建模
透明区域只用于装配腔、能量窗和 UI ghost slot
```

避免：

```text
纸箱物流风格
Create 黄铜齿轮风格
密集文字、数字、箭头、水印
赛博朋克屏幕墙
薄线缆和过多微细节
单一紫蓝渐变铺满全部资产
```
