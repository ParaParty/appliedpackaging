# 序列缓存器

<BlockImage id="appliedpackaging:sequence_buffer" scale="8" />

单个缓存器锁存一种 AE 资源键与数量，完全清空前不接受第二次输入；在游戏 tick `t` 清空后，从 `t + 1` 才重新开放。物品、流体与 ME 能力都操作这份真实状态。

## 输入与存储

一个成员通过一次真实插入锁存一种 AE 资源键；一旦非空，后续任何插入都会被拒绝，包括同一种资源。最初那次插入最多可接收服务端配置容量，默认 1024。物品、流体与通用 ME 传输共享同一锁存。清空后延迟一 tick 重开，可防止自动输出刚清空就在同 tick 接收下一批。

主 GUI 映射已成型结构的有序成员，侧面 GUI 映射玩家点击的实际方块。两者都操作同一份真实存储；即使自动输出延迟、阻挡或同步正在生效，玩家仍可通过 GUI 抽取。只有端点主 GUI 可以调整配置；成型成员侧面 GUI 只提供跳转到主方块的按钮，未成型单块没有配置或跳转按钮。

## 多方块所有权

两个以上缓存器可沿 X/Y/Z 直线组成多方块。端点持有配置并按稳定顺序代理全部成员 tick，端点自身不存储。对同一侧连续使用扳手时，方向严格按“点击面的对面方向 → 点击面方向 → 无方向”循环。

结构只能沿一个轴形成直线。端点持有配置并执行所有成员 tick，普通成员成型后不会自行 tick。尾部扩展保持成员顺序；破坏端点会整体解散，破坏中段只保留端点侧连续片段。

## 输出调度

成型多方块的自动输出可独立或同步执行；阻挡模式要求目标为空。输入延迟可为 0，红石卡控制自动输出。同步输出、样板模式和输入延迟只在多方块成立时生效；未成型单块不应用输入延迟。GUI 抽取明确不受延迟、阻挡或同步限制。

有方向成员只从配置面输出；无方向成员搜索除其它序列缓存器外的相邻兼容目标。同步输出要求所有已占用成员先找到完整目标，再允许任何成员提交；独立模式则逐成员判断。

输入延迟与红石只负责调度自动输出，不属于防堵塞准入条件，否则有意设置延迟的合法输入将永远无法进入。

## 配置速查

| 设置 | 效果 |
| --- | --- |
| 自动输出 | 开启成员向目标主动输出。 |
| 阻挡 | 自动输出前要求所选目标完全为空。 |
| 同步输出 | 所有已占用成员都通过预检后，才允许任何成员提交。 |
| 样板模式 | 使用包裹记录的稀疏位置，而不是紧凑条目顺序。 |
| 防堵塞 | 普通或原子输入前，要求按真实规则能够完整输出。 |
| 输入延迟 | 延迟 capability 抽取与自动输出，但不限制 GUI 抽取；预设为 0、1、5、10、20、40、100 tick。 |
| 输入过滤 | 最多九种 AE 资源键；全部为空时接受任意受支持资源。 |

安装红石卡后，只有端点收到信号才允许自动输出。成型成员实时读取端点权威配置并忽略自己的本地配置；成员 GUI 不允许修改设置，只能跳转到端点主 GUI。

## 样板模式与防堵塞

防堵塞模式默认关闭。开启后，普通输入或原子样板/包裹输入只有在每个目标成员都能按真实方向、目标、阻挡与容量规则完整输出时才被接收。样板模式保留已知稀疏位置；高级样板直接推送始终按设计使用紧凑顺序。

包裹输入时，卸货总线先构建一份原子分配计划。开启样板模式且存在已记录布局时，稀疏位置选择对应成员；否则按条目顺序紧凑填入。任一成员忙碌、过滤不符、容量不足或防堵塞输出预检失败时，所有成员都保持不变。

## 组成序列

将至少两个缓存器沿 X、Y 或 Z 轴排成直线。用 AE2 扳手点击端点侧面以循环输出方向并成型。端点持有配置，其余方块按顺序成为存储成员。
