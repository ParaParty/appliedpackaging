# ME 打包机

<BlockImage id="appliedpackaging:me_packager" scale="8" />

ME 打包机只通过底面和模型背面接入 AE2，不扫描相邻库存。打包时读取已连接的 ME 存储，应用颜色、标记与内容设置，并生成一个确定性包裹。红石模式控制自动打包，加速卡缩短真实工作周期。

## 网络连接与交互

水平朝向会同时旋转模型和背部接线面，底面接线始终有效，其它面不能连接 ME 线缆。使用 AE2 扳手旋转机器。

点击传送带表面可放入或取回唯一可见包裹；点击机框打开 GUI。GUI 与世界交互操作同一个真实 held 槽，不会产生隐藏暂存副本。

## 打包

设置标记、颜色、内容过滤与激活方式后，可手动或用红石触发一次打包。只有容量模拟和 ME 抽取模拟全部成功后才真正抽取。输入中包含包裹时会在原位置展开内容，包裹不会真实嵌套。

内容过滤与标记过滤是两条独立门禁；反转卡只反转内容过滤，不反转标记匹配。

## 配置速查

| 设置 | 效果 |
| --- | --- |
| 颜色 | 选择输出包裹颜色；若当前过滤规则提供颜色，则使用规则颜色。 |
| 保留标记 | 保留来源包裹中兼容的标记；来源标记冲突时整份计划失败。 |
| 覆盖标记 | 优先使用标记假槽；假槽为空时可使用当前过滤规则的标记。 |
| 清除标记 | 输出包裹不继承标记。 |
| 打包与拆包 / 仅打包 / 仅拆包 | 决定内容过滤作用于哪些操作；仅打包模式会拒绝包裹输入，因为拆包已关闭。 |
| 高信号 / 低信号 / 始终 / 脉冲 / 关闭 | 分别在有信号、无信号、持续、每次上升沿一次或仅手动时打包。 |

## 拆包、阻挡与防堵塞

输入包裹会向同一个 ME 存储拆包。现有**阻挡模式**可在网络存在可见资源时禁止拆包；独立的**防堵塞模式**默认为开启，只有包裹全部内容满足当前自动输出规则（包括阻挡模式与容量）时才接收。关闭后，合法包裹可以留在可见持有槽中等待并安全重试。

阻挡模式属于真实自动拆包规则，因此开启防堵塞时，阻挡失败就意味着机器拒绝包裹；关闭防堵塞时，同一个包裹会进入 held 槽等待。等待期间始终允许从 GUI 取回。

最终拆包会重新检查完整目标容量；失败重试不会插入部分内容。

点击传送带表面可放入或取回包裹；点击机框则打开 GUI。

## 升级

* <ItemLink id="ae2:speed_card" /> 缩短打包与拆包工作周期。
* <ItemLink id="ae2:capacity_card" /> 每张解锁一行过滤：初始两行，安装三张后达到五行。
* <ItemLink id="ae2:fuzzy_card" /> 与 <ItemLink id="ae2:inverter_card" /> 改变内容匹配方式。

独立的存储元件槽只接受 16k、64k 或 256k 元件，不接受 1k 元件、完整存储元件成品或便携式存储元件。
