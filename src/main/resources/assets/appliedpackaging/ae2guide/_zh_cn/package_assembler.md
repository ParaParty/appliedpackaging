# ME 包裹装配室

<BlockImage id="appliedpackaging:package_assembler" scale="8" />

装配室可执行 AE2 能解码的任意已编码样板。包裹/高级样板保留专用颜色、标记、顺序与稀疏布局；普通合成或处理样板使用装配室所选的颜色与标记。

## 样板与容量

本地样板槽接受 AE2 可以解码的已编码样板。包裹样板生成一个配置好的包裹；高级样板为每个启用列生成一个包裹；普通合成或处理样板按输入顺序生成一个所选颜色的包裹，并优先使用机器配置标记，标记槽为空时才回退到主产物。

消耗任何输入前，计划中的每个包裹都必须满足当前容量档。未安装元件时上限为 9 单位、9 种资源；AE2 16k、64k、256k 存储元件可选择更大容量。超限样板仍留在槽中供检查，但输入槽会锁定。

## 两种输入路径

它可原子接收样板供应器推送，也提供按位置过滤的真实本地输入槽。进度完成前材料仍可由玩家操作；更换样板会取消当前本地计划，暂时取走材料只会暂停。

样板供应器推送是原子的：在消耗输入计数器前先验证完整批次和所有输出包裹。本地模式使用真实的按位置过滤槽；只有进度达到 100% 且整份计划仍匹配时才消耗材料。

本地 GUI 用 4x4 窗口显示实际需要的输入位置；稀疏空位会被跳过，只有可见区之后确实还有真实输入时才允许滚动。

## 颜色、标记与容量控件

拾色器可选择福鲁伊克斯与 16 种染料色。没有本地样板或装入普通样板时，按钮显示并修改机器持久保存的选择；包裹样板会临时显示其编码颜色；高级样板各列同色时显示该色，不同色时显示 **无**。包裹或高级样板在槽内时颜色按钮不可单击，临时显示不会写回机器配置；取出样板后恢复此前的机器选择。样板供应器推送批次工作期间也按同一规则显示有效颜色。

标记槽是不消耗物品的配置槽。它只覆盖普通样板的主产物标记，不覆盖包裹样板或高级样板中的标记元数据。悬停容量元件区域会说明元件用途，并显示当前单位/类型上限。

批次工作期间，颜色、标记、输出模式与阻挡模式都不能修改，但仍会显示 hover tooltip；真实材料槽和已完成的有序输出仍允许玩家操作。

## 自动输出

自动输出可直接写入相连 ME 网络，或选定一个相邻容器。阻挡模式对新批次只检查一次；整批准入后会在同一 tick 内按真实队首连续输出，直到清空或目标拒收。GUI 始终操作同一份真实有序列表。

**ME 网络**直接写入装配室连接的 ME 存储；**相邻容器**从六个相邻位置中选择一个可接收目标，并在本批结束前锁定该方向。装配室没有专门的容器背面；**关闭输出**会把成品留在真实有序列表中，等待 GUI 或 capability 抽取。

阻挡模式只查找与本批任一包裹同类型的已有物品，无关物品不会阻挡。新批次通过阻挡检查且当前真实队首包裹可完整输入后即准入；不会预检后续包裹。随后按顺序排空，若目标中途拒绝当前队首，剩余真实列表继续留在 GUI 中。

切换输出模式不会复制或替换列表中已有包裹。玩家可以在两次自动输出尝试之间抽取，因为 GUI 与自动化始终共享同一份有序存储。

## 比较器状态

空闲为 0，正在打包为 1，仍有已完成包裹为 2。信号表示生命周期，不表示包裹数量。

它主要与 AE2 <ItemLink id="ae2:pattern_provider" /> 配合自动化。加速卡缩短工作周期；16k、64k、256k 存储元件选择共用包裹容量档。
