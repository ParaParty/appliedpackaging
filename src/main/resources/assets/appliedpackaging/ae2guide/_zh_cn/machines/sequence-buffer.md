# 序列缓存器

<BlockImage id="appliedpackaging:sequence_buffer" scale="8" />

一个包裹到货了——煤炭、铁、红石，按这个精心排列的顺序。但你的机器有三个不同的输入面，每个等不同的物品。怎么把一个包裹拆到三个目的地？

序列缓存器就干这个。

每个缓存方块恰好保存一种物品。把它们排成一行，用扳手操作端点，它们就组成一个多方块结构。包裹物品按顺序分配：条目 1 给第一个成员，条目 2 给第二个，条目 3 给第三个。每个成员通过自己配置的输出面送出。一个包裹，多个机器面，顺序全对。

## 单方块 vs 多方块

**单独一个序列缓存器也能正常用。** 它存一种物品，可以通过你选的任意面自动输出。简单场景——只需要往一个地方送一件东西——完全够用。

**多方块需要至少两个缓存器排成直线**（X、Y 或 Z 轴）。在末端方块的面上用扳手右键来组建结构。

* **端点**（你扳手操作的那个）拥有所有配置，但**不存东西。**
* **成员**（其他的方块）各存一种物品，从端点向外依次排列。

1. 排至少两个缓存器成直线。
2. 在远端用 AE2 扳手右键组建结构。
3. 打开端点 GUI 配置整体设置。
4. 每个成员打开侧边 GUI 选择输出方向。未指定方向的成员搜索任何兼容目标。
5. 把[包裹卸货总线](devices/package-unpacking-bus.md)贴在端点上喂包裹。

## 重要设置

### 自动输出
开着，成员自动推送物品。关着，物品留在里面等你自己取。干净利落。

### 阻挡模式
开着：成员等输出目标完全清空才送。关着：不管里面有没有东西照塞。和你见过的其他 AE2 阻挡模式一样。

### 同步输出
开着：**每个**已占用的成员都必须能输出，**任何**一个才动。理解为"全有或全无"。关着：各成员独立操作。

### 样板模式
当你的包裹编码时在物品间留了空位（稀疏布局），开这个。包裹记录的布局决定哪个槽位去哪个成员。关着就密集填充。

### 预接收检查
GUI 上叫"防堵塞模式"（默认关闭）。开了之后，缓存器在接受包裹之前检查每个分配到的成员能不能成功输出。任何成员会失败，整个包裹就不收。

### 输入延迟
在接受物品和输出之间加个间隔。0 到 100 tick（0 到 5 秒）。从 GUI 手动取不受延迟影响。

| 设置 | 作用 |
|------|------|
| 自动输出 | 成员自动推送物品 |
| 阻挡模式 | 等目标清空再输出 |
| 同步输出 | 所有成员一起输出，否则全等 |
| 样板模式 | 保留稀疏槽位位置 |
| 预接收检查 | 拒绝不能完全输出的包裹 |
| 输入延迟 | 接受/输出前的间隔（0–100 tick） |
| 输入过滤器 | 最多 9 种物品；空 = 接受一切 |

## 小贴士

* **破坏端点解散整个结构。** 破坏中间成员保留靠近端点的那段。
* 每个成员默认存 **1024 件物品**（服主可调）。
* 端点装**红石卡**让自动输出需要红石信号。
* 端点有 GUI，每个成员有侧边 GUI。都展示同一个真实存储——从哪抽取都行。
* 熔炉场景：成员 1 面向侧面（燃料），成员 2 面向顶部（矿石），底部用漏斗抽结果。
