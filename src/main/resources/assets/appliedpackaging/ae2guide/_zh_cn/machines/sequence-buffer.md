# 序列缓存器

<BlockImage id="appliedpackaging:sequence_buffer" scale="8" />

序列缓存器的每个方块存储一种物品类型，并将物品输出到配置的相邻面。它的作用是保留输入物品的顺序——无论来自包裹还是样板供应器推送——并将每件物品投递到正确的机器面。

每个缓存成员只接受一次插入，直到完全清空后才接受下一次。这个约束防止了相同物品的合并。例如，当样板指定煤炭在位置 1 和位置 3 时，缓存器保持它们独立，使得位置 1 的煤炭去往一个面，位置 3 的去往另一个面。包裹内容物、样板供应器的原料顺序和稀疏槽位布局都由缓存器保留。

将两个或更多序列缓存器沿 X、Y 或 Z 轴直线放置，可以组成多方块结构。在端面使用 AE2 扳手右键点击即可组建。被扳手操作的方块成为端点，负责保管配置但不存储物品。其余方块是存储成员，从端点向外依次编号。成员 1 接收序列中的第一个物品，成员 2 接收第二个，依此类推。

成员输出完成后会有短暂间隔才能再次接收物品，防止同一成员在同一游戏刻内被立即重新填入。

## 搭建步骤

</GameScene>

1. 将至少两个缓存方块排成直线。
2. 在端面使用 AE2 扳手右键点击以组建多方块。
3. 打开端点的 GUI 配置整个结构的设置。
4. 在成员的侧边 GUI 中设置各自的输出方向。未设置方向时，成员会自动搜索附近除序列缓存器之外的兼容目标。
5. 将包裹卸货总线贴在端点面上接收包裹。

## 设置

*   **自动输出**——每个成员将物品推送到其输出面。
*   **阻挡模式**——成员等待输出目标完全清空后才进行输出。
*   **同步输出**——所有成员都必须能够输出，任意一个才会实际输出。只要有一个成员不能输出，所有成员都会等待。
*   **样板模式**——保留编码样板或包裹布局中的稀疏槽位位置。关闭时，物品跳过空槽位按顺序填入成员。
*   **预接收检查**（GUI 中标注为"防堵塞模式"，默认关闭）——在接受包裹或样板推送之前，检查每个分配到的成员是否能够成功输出。如果有任何成员无法输出，整个输入将被拒绝。
*   **输入延迟**——在接受和输出之间添加 0 到 100 游戏刻的延迟。从 GUI 手动取出不受影响。
*   **输入过滤器**——最多 9 种物品或流体类型；留空则接受任何支持的资源。

## 容量

每个成员默认最多存储 1024 件物品。此值可由服务器配置修改。
