# Example Setups

Ready-to-build configurations for common packaging tasks. Each setup includes an interactive 3D scene, a parts list, and step-by-step instructions.

These setups are deliberately small — add your own storage, crafting CPUs, channels, and machine-specific input faces as your network grows.
